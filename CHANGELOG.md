# Changelog

All notable changes to PracticeLWC are documented here.

## [1.0.0] - 2026-11-07

- Initial curriculum release: 35 projects across 4 levels (API v67).
- Level 1 Beginner (1-9): first components, LDS, record forms, wizard, `lwc:on`, LWS-clean downloads.
- Level 2 Intermediate (10-18): imperative Apex, approvals, GraphQL reads and mutations, shared state, console, portal, Flow handoff, notifications.
- Level 3 Advanced (19-27): CPQ wizard, quote PDF, field planner, offline app, ops dashboard, TypeScript grid, SSR catalog, UTAM track, secure file hub.
- Level 4 Architect and Capstones (28-35): identity and consent, offline workbench, omnichannel hub, Lightning Out 2.0, feature lab, three end-to-end capstones.
