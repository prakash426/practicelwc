# Level 2: Intermediate (Projects 10-18)

Branch: `level/intermediate`. Prereq: Level 1. You will call Apex with confidence, run approvals, query with GraphQL, share state between components, and hand off to Flow.

| # | Project | You will learn | Docs |
|---|---|---|---|
| 10 | Discount Eligibility Checker | Imperative Apex, `{ data, errors }`, toasts | [README](projects/10-discount-checker/README.md) |
| 11 | Approval Inbox | Datatable inbox, modal, platform events, `refreshApex` | [README](projects/11-approval-inbox/README.md) |
| 12 | GraphQL Opportunity Explorer | `@wire(graphql)` relational reads, tree grid | [README](projects/12-graphql-opportunity-explorer/README.md) |
| 13 | GraphQL Mutations Editor | `executeMutation`, inline edit, error branches | [README](projects/13-graphql-mutations-editor/README.md) |
| 14 | Shared Cart State | LWC State Management singleton, sibling sync | [README](projects/14-shared-cart-state/README.md) |
| 15 | Agent Console Workspace | Console APIs, LMS siblings, macros, timeline | [README](projects/15-agent-console-workspace/README.md) |
| 16 | Partner Portal Dashboard | Experience targets, sharing safe Apex, files | [README](projects/16-partner-portal-dashboard/README.md) |
| 17 | Flow Handoff | Nav to Flow, local flow actions | [README](projects/17-flow-handoff/README.md) |
| 18 | Notification Center | Custom notifications, live badge, modal detail | [README](projects/18-notification-center/README.md) |

Jest suites ship for 8 of 9 projects (15 is Apex covered). Project 17 reuses the `Approval_Request__c` object from project 11.
