# Level 4: Architect and Capstones (Projects 28-35)

Branch: `level/capstone`. Prereq: Levels 1-3. Multi brand identity, large scale offline, omnichannel routing, Lightning Out 2.0, release engineering, then three end to end capstones that compose the whole curriculum.

| # | Project | You will learn | Docs |
|---|---|---|---|
| 28 | Multi-Brand Identity and Consent Console | Consent toggles, audit events, brand segregation | [README](projects/28-identity-consent-console/README.md) |
| 29 | EX-Rated Offline Workbench | Offline at scale, thresholds, telemetry embeds | [README](projects/29-offline-workbench/README.md) |
| 30 | Omnichannel Support Hub | Bot handoff, routing services, analytics tiles | [README](projects/30-omnichannel-hub/README.md) |
| 31 | LWC Beyond Salesforce (Lightning Out 2.0) | Declarative tag, OAuth, CORS, external host page | [README](projects/31-lightning-out-embed/README.md) |
| 32 | Release-Gated Feature Lab | Preview channels, HMR, Error Console runbook | [README](projects/32-release-feature-lab/README.md) |
| 33 | Capstone A: Lead to Cash | Web lead to signed quote PDF in one demo | [README](projects/33-capstone-lead-to-cash/README.md) |
| 34 | Capstone B: Case to Resolution | Self help to console to offline field fix | [README](projects/34-capstone-case-to-resolution/README.md) |
| 35 | Capstone C: Portal to Insight | Portal plus SSR plus Out 2.0 from one package | [README](projects/35-capstone-portal-to-insight/README.md) |

Each project README carries an architecture section with a mermaid sequence diagram. Capstones reuse earlier projects rather than adding new objects; run the demo scripts on a scratch org and keep Jest plus UTAM green.
