# Level 1: Beginner (Projects 1-9)

Branch: `level/beginner`. Start here if LWC is new. By the end you can read and write records, wire Apex, build a wizard, and ship LWS clean downloads.

| # | Project | You will learn | Docs |
|---|---|---|---|
| 1 | Hello Lead Card | Templates, `@api`, `getRecord`, illustration fallback | [README](projects/01-hello-lead-card/README.md) |
| 2 | Lead Worklist Table | `@wire` Apex, datatable, `refreshApex`, toasts | [README](projects/02-lead-worklist-table/README.md) |
| 3 | Lead Convert Form | Record edit form, imperative Apex, navigation | [README](projects/03-lead-convert-form/README.md) |
| 4 | Knowledge Self-Help Finder | Debounce, accordion, LMS publish, `lwc:on` | [README](projects/04-knowledge-finder/README.md) |
| 5 | Case Creator with Attachments | LMS subscribe, `createRecord`, file upload | [README](projects/05-case-creator-attachments/README.md) |
| 6 | Project Intake Wizard | Multi step wizard, validation, progress | [README](projects/06-project-intake-wizard/README.md) |
| 7 | Dynamic Event Playground | `lwc:on` event maps, mode switching | [README](projects/07-dynamic-event-playground/README.md) |
| 8 | Record Header Widgets | Builder props, view form, SLDS hooks | [README](projects/08-record-header-widgets/README.md) |
| 9 | Download Center | `Blob` CSV download, LWS lint, empty state | [README](projects/09-download-center/README.md) |

Shared utilities introduced here: `utilsLib`, `errorPanel`, `emptyStateWrap`, plus the `Project__c` object and the `SearchTerm` message channel. All nine projects ship passing Jest tests.
